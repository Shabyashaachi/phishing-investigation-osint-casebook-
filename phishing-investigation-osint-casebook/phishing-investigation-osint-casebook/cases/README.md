# Cases

Five investigations, cumulative in depth. Cases 001–003 establish the primitives on a single
January 2026 wave; Case 004 applies correlation discipline to what they produced; Case 005
runs the full methodology against a more capable February wave from the same campaign.

| # | Case | Primary skill | Key judgement |
|---|---|---|---|
| [001](case-001-email-header-investigation/) | Email Header Investigation | Header chain, SPF/DKIM/DMARC alignment | Credential phishing from unauthorised infrastructure (High) |
| [002](case-002-phishing-url-investigation/) | Phishing URL Investigation | Redirect chains, cloaking, hosting context | Personalised credential-collection page via abused redirector (High) |
| [003](case-003-phishing-domain-investigation/) | Phishing Domain Investigation | RDAP/DNS/CT, indicator limitations | Domain staged for the campaign (High); sibling domain probably related (Medium-High) |
| [004](case-004-infrastructure-correlation/) | Infrastructure Correlation | Selectivity, falsification, rejected edges | Core cluster confirmed; ~900 co-tenants explicitly excluded |
| [005](case-005-eu-fin-001-credential-phishing-campaign/) | **EU-FIN-001** (flagship) | End-to-end campaign investigation | AiTM reverse proxy capable of session-token capture (High) |

All scenarios are synthetic. See [DISCLAIMER](../DISCLAIMER.md).
