# Evidence — CASE-004

This case is analytical rather than collection-driven: it re-examines evidence gathered in
CASE-001 to CASE-003 and tests the relationships between those elements.

Source records:
- Headers and sending infrastructure — [CASE-001 evidence](../../case-001-email-header-investigation/evidence/)
- Redirect chain and hosting — [CASE-002](../../case-002-phishing-url-investigation/)
- RDAP, DNS and CT — [CASE-003](../../case-003-phishing-domain-investigation/)

The output of this case is the **edge register** in [`../investigation.md`](../investigation.md) §4,
which is the evidential artefact: each edge is independently checkable against the source
records above.
