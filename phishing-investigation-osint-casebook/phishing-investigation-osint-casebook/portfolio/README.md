# Portfolio Materials

Supporting material for applications. Kept in the repository deliberately: a reviewer can see
exactly what claims are being made about this work elsewhere, and check them against the work.

| Document | Contents |
|---|---|
| [cv-and-linkedin.md](cv-and-linkedin.md) | Three CV entry versions (ATS one-line, two-bullet, three-bullet technical) and three LinkedIn posts |
| [interview-preparation.md](interview-preparation.md) | Twenty technical questions with what is being tested, a strong answer, a follow-up and the common mistake |
| [hiring-manager-review.md](hiring-manager-review.md) | Critical self-review in the voice of a European hiring manager: demonstrated skills, weak evidence, missing evidence, likely questions, pre-publication fixes |

All wording describes **independent security research**. Nothing claims employment, client
work, or handling of real incidents.
