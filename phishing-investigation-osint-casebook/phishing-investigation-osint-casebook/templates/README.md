# Templates

Reusable structures. Copy into a new case folder and fill.

| Template | Use |
|---|---|
| [`phishing-investigation-template.md`](phishing-investigation-template.md) | Working investigation record |
| [`CTI-report-template.md`](CTI-report-template.md) | Formal technical report |
| [`executive-brief-template.md`](executive-brief-template.md) | One-page leadership brief |
| [`IOC-template.csv`](IOC-template.csv) | Indicator export schema |
| [`evidence-manifest-template.md`](evidence-manifest-template.md) | Evidence provenance and integrity |

Every template carries the same discipline: observation separated from assessment, confidence
stated with justification, alternative explanations recorded, and intelligence gaps present
by default rather than added if there is room.
